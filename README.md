## 📖 Merge vs Rebase

### Git Merge

- Combines two branches.
- Creates a merge commit.
- Preserves complete branch history.
- Recommended for team collaboration.

### Git Rebase

- Moves commits to the latest base branch.
- Produces a cleaner, linear commit history.
- Rewrites commit history.
- Best used on local branches before sharing.
