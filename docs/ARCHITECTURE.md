# Architecture

## What this is

Git & GitHub Practice 🚀. This repository was created to practice and demonstrate fundamental Git and GitHub workflows, including version control, branching, pull requests, merge conflicts, and collaboration. The repository has no framework manifest beyond the files listed.

## Layout

- Root files: `about.txt`, `contact.txt`, `profile.txt`, `README.md`

## How the pieces fit

The pieces are the top-level files and directories listed above.

## How to run

Commands written in the README:

```
git init
git clone
git add
git commit
git status
git log
git branch
git checkout
git merge
git pull
git push
```
